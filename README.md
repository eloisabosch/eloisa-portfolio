# Portfolio — Eloísa Bosch
1. `npm install` y `npm run dev` → http://localhost:3000
2. Todo el contenido está en `data/portfolioData.js` (bio, links, proyectos, coordenadas del mapa, pasos del formulario).
3. Imágenes en `public/images/` y se referencian como "/images/archivo.jpg". CV en `public/cv-eloisa-bosch.pdf`.
4. Nuevo proyecto: copiar un objeto de `projects`, cambiar `slug`, `x`, `y`, `links`.
